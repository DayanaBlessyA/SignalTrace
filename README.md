# SignalTrace

**Telecom Investigation and Analytics Platform**

SignalTrace is a web-based investigation support platform designed to analyse sample Call Detail Records (CDR) and Internet Protocol Detail Records (IPDR).

## Features
- Dashboard overview
- CDR and IPDR CSV data import
- Communication analysis
- Common contact identification
- Tower timeline
- AI assistant interface
- Reports and audit logs

## Technology Stack
- HTML
- CSS
- JavaScript
- Chart.js

## Project Structure
- `index.html` – Website structure
- `style.css` – Website styling
- `script.js` – Application functionality
- `data/` – Sample datasets for testing

## Getting Started
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Navigate through the available sections.
4. Import the provided sample CSV files to explore the prototype.

## Note
This is an educational prototype. It uses sample datasets and is not intended for real-world law enforcement investigations.
